# Lithium Adsorbent ML

An open and reproducible framework for constructing structure–performance datasets and machine-learning workflows for lithium-selective adsorbents.

## Scope

This repository provides reusable tools for:

- standardized extraction of lithium adsorbent literature data;
- descriptor definition and structure–performance dataset construction;
- machine-learning-ready data templates;
- descriptor frameworks for interpretable modeling and reverse materials design;
- reproducible preprocessing and analysis workflows.

## Repository Structure

- `docs/` — data extraction guidelines and descriptor definitions
- `data-template/` — standardized database templates
- `scripts/` — reproducible dataset construction utilities
- `notebooks/` — example analysis workflow documentation

## Current Status

The project is under active development. Public components are released progressively while unpublished research data and manuscripts remain in a separate private research repository.

## Intended Use

The framework is designed for researchers studying lithium extraction, selective adsorption, functional adsorbents, and machine-learning-assisted materials discovery.

## Citation

Citation information will be added with future dataset/software releases.

## Quick Start

1. Review the descriptor definitions in `docs/`.
2. Use `data-template/lithium_adsorbent_structure_performance_template.csv` as the standardized structure–performance data schema.
3. The `scripts/` directory contains utilities for reproducible dataset construction.

The public workflow is being progressively validated and documented. Execution examples and demonstration data will be added in subsequent releases.
