# Notebooks

This folder contains placeholder notebooks for analysis tasks that should be performed after the literature matrix has been populated with verified records.

## Planned Notebooks

- `01_literature_statistics.ipynb`: summarize publication counts, material classes, targets, models, descriptors, and validation status.
- `02_keyword_mapping.ipynb`: map keywords, adsorbent types, targets, descriptor categories, and ML methods.
- `03_figure_generation.ipynb`: generate preliminary charts or figure components from curated matrix data.

## Data Rules

Use only verified records from the literature matrix. Do not use notebook outputs as manuscript evidence unless the underlying sources are documented in the matrix.
